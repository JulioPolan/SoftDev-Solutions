# TaskManager

## Descripción

TaskManager es una aplicación web desarrollada por SoftDev Solutions cuyo propósito es facilitar la administración y seguimiento de tareas y actividades dentro de equipos de trabajo. La plataforma permite organizar, asignar, monitorear y controlar el progreso de las actividades, mejorando la colaboración y la productividad de los usuarios.

## Objetivos del Proyecto

* Centralizar la gestión de tareas en una sola plataforma.
* Facilitar la asignación de actividades a los miembros del equipo.
* Monitorear el estado y avance de las tareas.
* Mejorar la comunicación y coordinación entre los integrantes del equipo.
* Optimizar el control y seguimiento de proyectos.

## Características Principales

* Registro e inicio de sesión de usuarios.
* Gestión de roles y permisos.
* Creación, edición y eliminación de tareas.
* Asignación de tareas a miembros del equipo.
* Definición de fechas de inicio y vencimiento.
* Seguimiento del estado de las tareas (Pendiente, En progreso, Completada).
* Visualización de listas de tareas y reportes.
* Interfaz web intuitiva y fácil de usar.

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/JulioPolan/SoftDev-Solutions.git
```

2. Ingresar al directorio del proyecto:

```bash
cd taskmanager
```

3. Instalar dependencias:

```bash
npm install
```

4. Configurar la base de datos MySQL.

5. Ejecutar la aplicación:

```bash
npm start
```
## Roles de Usuario

### Administrador

* Gestionar usuarios.
* Crear y asignar tareas.
* Supervisar el progreso general.

### Miembro del Equipo

* Consultar tareas asignadas.
* Actualizar el estado de las tareas.
* Registrar avances y comentarios.

## Estado de las Tareas

| Estado      | Descripción                         |
| ----------- | ----------------------------------- |
| Pendiente   | La tarea aún no ha iniciado         |
| En Progreso | La tarea se encuentra en desarrollo |
| Completada  | La tarea ha sido finalizada         |
